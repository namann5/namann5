### What I'm building right now

**NEXUS** — an AI-powered criminal network intelligence workbench, built for Smart India Hackathon (Ministry of Home Affairs problem statement, Blockchain & Cybersecurity theme). It takes in raw case data and turns it into an investigator-usable knowledge graph: entity extraction → entity resolution → relationship mapping → graph analytics. Stack: React/TypeScript + Cytoscape.js on the front end, Node/Express + Python/FastAPI on the back end, Neo4j + PostgreSQL for the data layer.
