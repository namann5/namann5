## 🧑‍💻 About

I'm a backend and security engineer based in Agra, Uttar Pradesh, India. I like finding the
holes before someone else does — auth flows, token handling, injection paths — and I care
about software that survives a hostile input. Open to internships, remote roles and freelance work.
